# Start CampusCompass 2.0

**Team AetherMind · PE-B37-13 · Bennett University**

1. Extract the ZIP and open `CampusCompass.html` for the offline app.
2. Choose **Attendance** to see a cited answer, or use **Refine scope** to look up a calendar entry for a specific cohort.
3. Run `node source/server.js` from this folder to use the local API at [http://127.0.0.1:8000](http://127.0.0.1:8000).
4. Run `npm test` to verify the evidence engine, API, recorded experiments and app builds.
5. Read `README.md` for API details and optional model setup. The original academic submission and recorded demo are in `final/`.
