# CampusCompass - 120-second progress demonstration

Synthetic narration; real application captures and retained inference outputs. Edited demonstration, not an uninterrupted live-session recording.

## 0-15 seconds / CampusCompass

Campus Compass is our source grounded campus helpdesk prototype. It makes the evidence, prompt and limitations visible. This milestone includes a working application, actual local model experiments, and reproducible checks.

## 15-30 seconds / An answer with a source

A student asks about attendance. The application displays a curated answer, a source quote and a page reference. It also warns that this historical notification needs a current applicability check.

## 30-45 seconds / Missing scope is a decision

When a fee question lacks scope, the assistant asks for the programme, year and category. It does not invent an amount or attach a source that does not support the answer.

## 45-60 seconds / A real model failure

We ran the same eight questions across six prompt versions with a small local Qwen model. Version three produced valid JSON, but selected unrelated facts. The validator rejected that result.

## 60-75 seconds / A focused schema refinement

Version four copied a schema placeholder into two outputs. Version five changed only that schema representation. The same development cases then passed all eight contracts. This is a pilot result, not a reliability guarantee.

## 75-90 seconds / Reject an invented fact

The Prompt Studio exposes the full assembled prompt. Here, an invented fact ID is held for review. Only approved selections can reach the renderer, which supplies the curated wording and source ledger.

## 90-105 seconds / Keep the measures separate

The package keeps all forty eight comparative model outputs. Separately, component checks match thirty nine of forty two expected statuses. Three paraphrase misses remain documented, even though retrieval found the right cards.

## 105-120 seconds / Inspect. Reproduce. Explain.

Open the standalone application, inspect the evidence, replay the experiments, and rerun the checks. Next, we will expand source coverage and use independent evaluation. This demonstration uses a synthetic narrator and verified application captures.
